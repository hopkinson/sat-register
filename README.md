# SAT 本机控制台

在 Windows 电脑上管理考生任务。控制台和浏览器都在本机运行，不需要购买服务器、部署 Docker 或安装 Chrome 插件。

## 启动

双击 `启动.bat`。启动成功后自动打开 `http://127.0.0.1:3000`。也可在项目目录运行 `npm start`。

首次使用需要 Node.js 18 或更新版本，并在项目目录执行：

```powershell
npm install
npx playwright install chromium
```

保持启动窗口开启，电脑不要休眠。关闭控制台网页不会停止任务；在启动窗口按 Ctrl+C 会停止服务及浏览器任务。不要同时启动多个服务实例。

## 使用

1. 先在“设置”中配置全局 SAT 账号和密码。创建考生任务时只需填写姓名、考期、考区和考点，可选上传照片，无需重复填写账号密码。所有任务在启动时读取当前全局凭证，包括已有任务；修改配置后，正在运行的任务需要停止并重新启动才会使用新凭证。
2. 保存后，在任务卡片点击“启动监控”。每个任务使用独立浏览器资料目录，默认弹出可见窗口。
3. 正常登录自动使用保存的账号密码，并按名称选择 Password 认证方式。首页优先续办目标考期的未完成报名；无法唯一定位时保留浏览器提示人工进入正确报名。考试规则默认人工当次确认接受；在“设置”中开启“自动接受考试规则”后，系统自动滚动条款至底部、勾选复选框并点击 Continue，任一步骤失败仍转人工当次确认。Arkose 验证码在“设置”中配置 YesCaptcha 密钥后自动识别并注入，注入后页面未推进、打码失败或未配置密钥时任务显示“待人工核对”，请在对应浏览器完成处理；每次运行自动识别最多尝试 6 次且两次间隔至少 30 秒，避免无谓消耗打码次数。处理完成后自动恢复查位，无需重新启动。日期按年份分组匹配，并核对完整考期；无法确认时等待人工处理，不会选其他日期。
4. 自动尝试选座后，控制台显示“待人工核对”，并说明当前是停在确认页、进入报名后续页面、需要人工验证码，还是结果未确认。上述情况均不证明官网已经锁位，不生成锁位倒计时；结果不明或遇到验证码时暂停自动推进，保留浏览器供人工处理。核对考期、考点及金额，在官网人工提交支付。
5. 确认官网报名和付款成功后，点击控制台“确认已付款”。完成或删除任务会清理该任务的照片、截图和浏览器资料目录；数据库任务记录由相应操作保留或删除。

本机版不自动提交付款，即使旧设置里保存了自动扣款开关。单个任务停止或关闭浏览器后，可重新启动。服务重启后，旧运行状态恢复为“未启动”，需要先核对官网实际状态，再手动启动。

个人信息向导保留官网已有的学校、年级和问卷答案，不按下拉框位置代填。遇到弹窗、必填项缺失或 Continue 未推进时，任务显示“待人工核对”并说明原因；在浏览器处理后自动恢复。继续前请核对已有资料是否准确。

选座页的 hCaptcha 回填令牌不等于官网验证通过。需要人工验证时，在任务浏览器完成即可，无需回到聊天确认；本机任务持续核对官网控件、目标考期和考点，验证完成后自动接续一次选座提交。若会话已过期，旧验证结果不可沿用。提交接口报错时保留浏览器和结果，不自动重放请求。

任务卡片的“编辑”支持修改考期、补传、更换或移除证件照。运行中需先暂停，已完成任务不能编辑。改期后需重新确认考点；保存后保持未启动，保留任务和历史日志。编辑只修改本地配置，不会同步修改官网已有报名；若已进入报名流程，请人工核对官网考期、考点及照片。照片支持不超过 5 MB 的 JPG、PNG、WebP。

## 程序结构

```text
启动.bat / npm start
  → start-local.js：检查依赖、浏览器，启动服务
  → server.js：本机任务管理、日志推送、数据保存
      ├─ public/index.html：控制台
      └─ sat-engine.js：Playwright 操作独立浏览器
```

所有任务及配置保存在 `data/db.json`，浏览器登录状态保存在 `data/profile_<任务ID>`。服务只监听 `127.0.0.1`，不提供局域网或公网访问。数据仍以明文保存在本机，请勿上传或共享 `data`，备份时同样保护好账号和支付资料。

两个旧的极速 BAT 现在也进入同一控制台。`api-fast-locker.js` 和 `sat-monitor.user.js` 是保留的历史实现，不参与本机控制台运行，请勿同时启用。浏览器插件源码及专用测试已移除；如浏览器中仍安装着旧插件，请先将所需任务录入本机控制台，再单独停用或移除已安装插件。Python、视频帧和 OCR 文件仅用于分析操作录像。

## 验证与限制

新建任务的国家／地区名单每次从 College Board 官方公开字典在线获取，不保存本地名单或在失败时读取旧列表。考试日期同样每次从官方考期接口在线获取，替代手动输入；加载失败时需刷新重试后才能新建。地区与考点加载失败时需刷新重试后才能新建；切换考期或地区后会清除旧考点。编辑任务显示已保存的地区配置，地区不在编辑范围内；编辑时可改期，官网考期加载失败时仍可按已保存考期保存。

当前新建任务支持国际考区，美国需要邮编与距离查询，暂未支持；已有任务记录保留。官网公开字典及考点服务可能有官方缓存，“获取于”只表示本次获取时间，实际考位仍以登录后的报名查询为准。

官网实测的登录、已有报名、考试规则、考点查询步骤及当前自动化差异见 [官网操作步骤与实测记录](docs/official-flow.md)。

运行 `npm test`：使用临时数据及模拟官网检查本机服务、全局凭证使用与更新、重试、浏览器交接和日期匹配，不读取真实账号，不提交官网报名和付款。

官网页面、风控和登录步骤可能变化。自动查位和选座不保证报名成功，最终以官网为准。当前尚未测定多任务容量，先用一个任务确认流程，再增加并发。
